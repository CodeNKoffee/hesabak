# Contributing

Hesabak is open source under the [MIT licence](https://github.com/CodeNKoffee/hesabak/blob/main/LICENSE): use it, fork it, build on it. Contributions back are welcome.

The full guide is [CONTRIBUTING.md](https://github.com/CodeNKoffee/hesabak/blob/main/CONTRIBUTING.md). The short version:

- **No trackers, no outside requests.** Data never leaves the browser.
- **No build step, no dependencies** in the app.
- **One A4 page** per invoice and receipt, in every template.
- **Fictional data only** in screenshots, tests and examples.

## Editing this wiki

The wiki's pages live in the main repository under [`docs/wiki/`](https://github.com/CodeNKoffee/hesabak/tree/main/docs/wiki), so changes go through pull requests like any other. Maintainers publish them with `scripts/publish-wiki.sh`. Edits made directly on the wiki are overwritten at the next publish.
