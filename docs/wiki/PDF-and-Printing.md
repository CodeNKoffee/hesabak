# PDF and printing

Press **Save PDF**, then choose **Save as PDF** as the destination. The file is named after the invoice or receipt number.

For a clean result:

- Turn **off** "Headers and footers" in the print dialog (under **More settings** in Chrome). Otherwise the browser adds its own date and address to the page.
- Leave margins on **Default** or **None**; Hesabak sets its own A4 margins.
- Keep **Background graphics** on so tinted boxes and the Bold masthead print.

Everything fits on **one A4 page**. If you add so much text that it no longer fits, a warning appears above the page: shorten a note, shorten item descriptions, or hide a block on **Design**.
