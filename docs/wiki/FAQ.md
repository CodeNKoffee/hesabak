# FAQ

**Is it really free?**
Yes. There is no paid plan, no account and no server cost to pass on.

**Can anyone else see my invoices?**
No. They exist only in your browser. Hesabak has no server to send them to.

**I cleared my browser and my invoices are gone. Can you recover them?**
Not unless you exported a backup. See [[Your Data and Backups]].

**Can I use it on my phone?**
Yes. The editor stacks above the page. Dragging blocks doesn't work on phones, so use the arrows instead.

**Does it support Arabic invoices?**
Arabic text displays, but right-to-left layout is on the roadmap. Native speakers who can help are welcome; see [[Contributing]].

**Can I add my logo as an image?**
Not yet; the wordmark is text. Logo upload is on the roadmap.

**What's the difference between an invoice and a receipt?**
An invoice asks to be paid; a receipt confirms you were. See [[Receipts]].

**My PDF has a date and web address at the top.**
Turn off "Headers and footers" in the print dialog. See [[PDF and Printing]].

**Why does the day count round down?**
So the client never pays for part of a day you didn't work. See [[Billing and Tax]].
