# Install and offline

Hesabak is a progressive web app, so you can install it like a normal app.

| Browser | How |
|---|---|
| Chrome or Edge on a computer | The install icon at the right end of the address bar |
| Safari on a Mac | **File → Add to Dock** |
| Safari on iPhone or iPad | **Share → Add to Home Screen** |
| Chrome on Android | **⋮ → Add to Home screen** or **Install app** |

After the first visit it works with no connection. Updates arrive the next time you open it online.
