# Code of conduct

Hesabak follows the [Contributor Covenant, version 2.1](https://www.contributor-covenant.org/version/2/1/code_of_conduct/).

In short: be respectful, welcome newcomers, accept feedback gracefully, and focus on what is best for
the people using the app. Harassment, discrimination, personal attacks and publishing others' private
information are not acceptable.

To report a problem, open a private report through the repository's **Security** tab, or contact the
maintainer through [hatemsoliman.dev](https://hatemsoliman.dev). Reports are handled privately.
